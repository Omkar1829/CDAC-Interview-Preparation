## Rules

- Use Java.
- No AI-generated final answer without understanding it.
- Write dry runs for medium and hard problems.
- Include complexity for every solution.

## Problems

| Level | Problem | Required Concepts |
|---|---|---|
| Easy | Largest and second largest in array | traversal, comparison |
| Easy | Reverse string manually | two pointers or char array |
| Medium | Move zeroes to end | two pointers |
| Medium | Valid anagram | frequency array/map |
| Hard | Maximum subarray sum | Kadane's algorithm |
