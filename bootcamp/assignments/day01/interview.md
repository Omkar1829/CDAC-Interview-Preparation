# Day 01 Interview Drill

## Java Rapid Fire

1. Define JVM in one sentence.
2. Define JRE in one sentence.
3. Define JDK in one sentence.
4. What is bytecode?
5. What is class loading?
6. Where are objects stored?
7. Where are local variables stored?
8. Why is String immutable?
9. What is the difference between `==` and `.equals()`?
10. What is garbage collection?

## Project Drill

Explain your selected project using this structure:

1. Problem
2. Users
3. Features
4. Architecture
5. Database
6. Your contribution
7. Hardest bug
8. What you would improve

## HR Drill

Question: Tell me about yourself.

Constraint: 60-90 seconds. No generic lines. Mention skills, project, learning attitude, and interview role fit.
