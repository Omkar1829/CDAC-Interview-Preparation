# Day 01 Plan

## Morning - Java Revision and Theory

Time: 3 hours

1. JVM vs JDK vs JRE
2. Java memory areas: heap, stack, method area, PC register, native stack
3. Object lifecycle: class loading, object creation, constructor, reachability, garbage collection
4. Arrays and Strings basics

## Afternoon - DSA and SQL

Time: 3 hours

1. Arrays: traversal, max/min, frequency, prefix sum
2. Strings: reverse, palindrome, character counting
3. SQL: SELECT, WHERE, ORDER BY, GROUP BY, HAVING, LIMIT/TOP equivalent

## Evening - Project and Interview

Time: 2 hours

1. Choose one project to explain in interviews
2. Write the problem statement, modules, tech stack, and your role
3. Answer Java interview questions aloud

## Night - Revision and Reflection

Time: 1-2 hours

1. Revise flashcards
2. Log mistakes honestly
3. Mark weak topics
